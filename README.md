# Лабораторна робота № 3 — «Колекції та структури даних»

## Мета роботи
Ознайомлення з методами роботи з одновимірними та багатовимірними масивами у мові Java, генерацією випадкових чисел, зчитуванням даних через `Scanner`, сортуванням та перевантаженням стандартних методів `Object` (`toString`, `equals`).

## Основний функціонал (`ArrayManager`)
* **Конструктор:** Створення двовимірного масиву за заданими розмірами (рядки та стовпчики).
* **Заповнення випадковими числами:** Використання класу `Math.random()`.
* **Заповнення з клавіатури:** Перевантажений метод для зчитування значень через `Scanner`.
* **Сортування (`sortAll`):** Збирання елементів двовимірного масиву, сортування методом `Arrays.sort()` та розміщення назад по рядках у порядку зростання.
* **Перевантаження методів:** Реалізовано форматування виведення через `toString()` та поелементне порівняння через `equals()`.
